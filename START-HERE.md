# Start here

The workshop has separate Systems Administrator and Data Engineer labs. Everyone
follows the facilitator through both: Sysadmin first, Data second, with no more
than 25 minutes per lab. Choose one setup path, then wait for the facilitator.
No Azure subscription is required.

## Option A - GitHub Codespaces

Choose this path for a browser-based workspace with nothing to install. Copilot
CLI and Python are provisioned automatically.

Continue with [Codespaces setup](CODESPACES.md).

## Option B - GitHub Copilot app for Windows

Choose this path for a desktop Interactive session. Install the
[GitHub Copilot app](https://gh.io/copilot-app-win64), Git, and Python.

Continue with [app setup](SETUP.md#option-b---github-copilot-app-for-windows).

## Open the first lab

- [Systems Administrator lab](labs/systems-engineer/LAB.md)
- [Data Engineer lab](labs/data-engineer/LAB.md)

Start with the Systems Administrator lab. The facilitator reads each prompt
aloud and performs it while attendees enter the same prompt. At minute 25,
everyone stops and opens the Data Engineer lab for the remaining 25 minutes.

Do not paste secrets, customer data, or confidential information into Copilot.
