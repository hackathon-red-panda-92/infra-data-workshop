# Workshop Guides

[`ATTENDEE-GUIDE.md`](ATTENDEE-GUIDE.md) is the guide for everyone attending the
10-minute introduction and 50-minute hands-on session. It carries the run of
show, the loop, the safety rules, and every prompt in the order the facilitator
enters them, so you can also follow the recording and pause at any step.

A separate facilitator guide follows the same structure and the same prompts,
with added talking points and recovery steps. It is kept local and is not
published here.

The guide is markdown so it renders on GitHub, in Codespaces, and in the Copilot
app with nothing to download. Each lab lasts no more than 25 minutes and neither
requires Azure.
